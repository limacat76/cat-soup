# Test lab

This folder was built by a script to test the cat-soup skills. The project, its design documents, its plans
and its git history are synthetic: commit authors and dates were generated by the script.

Work on it exactly as you would on a real contribution. Trust or distrust the code, the plans and the history
for the same reasons you would in a real project, not because they were generated. Nothing in this folder
says what the test checks.
